# 个人仓库规则模板首版

- **日期** 2026-11-25
- **状态** 已交付

## 目标

让新仓库能快速采用同一套基础约定，让已有仓库能按需合并规则，同时保留各项目自己的工具和流程。

## 范围

- 在 `meta-rule` 中说明采用方式，并用本仓库自身的文件示范如何维护约定。
- 提供 README、AGENTS、Git 忽略规则和 EditorConfig 四份基础模板。
- 提供可选的工作日志、发版记录和 PRD 模板。
- 首版采用手动复制和合并。自动同步和远程发布可以在后续版本按需规划。

## 验收标准

- [x] 阅读根目录 README 后，可以定位并复制基础模板，知道已有仓库如何合并配置。
- [x] 各模板放到示例项目的对应路径后可以使用，项目专属内容有明确填写提示。
- [x] AGENTS 说明验证要求和各类文档的更新时机。
- [x] 仓库内文档链接可达。忽略规则保留可提交的环境变量示例文件。
